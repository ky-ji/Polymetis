# 连续关节跟随

`JointServoControl(..., lookahead_s=0)` 保持原来的零终端速度轨迹。显式启用 `lookahead_s`（最多 0.06 秒）后，控制器使用收到的目标差分估计速度，经过 20 ms 时间常数滤波，再将目标前移 `估计速度 × lookahead_s`。估计速度不超过配置的速度上限；目标也限制在原位置范围内。

预测只在收到新序号时计算，不在输入中断后继续外推。首次输入、暂停及超过 25 ms 的采样间隔重置估计。候选轨迹仍以零速度、零加速度结束，且整个轨迹的位置极值都必须通过检查。原有输入超时、乱序、非有限值和时钟倒退处理保持有效。

预测会改变停手和反向时的响应，可能增加短暂过冲。偏移上限不是机械臂实际过冲的保证。默认关闭以兼容现有部署；启用时需要同步部署 Python 策略和原生库。51 项旧配置仍可加载，非零预测使用 52 项配置，旧库会明确拒绝。

`streaming_probe` 使用 200 Hz、12 bit 量化输入与 1 kHz 参考更新，比较正弦、斜坡停止和边界反向；还检查暂停、恢复、丢包停车及参数校验。它支持额外速度上限参数，CTest 覆盖 0.35 和 0.5 rad/s。`reference_replay_test` 同时覆盖开启预测的历史边界轨迹。`test_server_roundtrip.py --lookahead-s ...` 在合成反馈上检查 TorchScript 上传、原生执行和超时停车，不连接真机。
