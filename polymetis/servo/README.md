# 连续关节跟随

`JointServoControl(..., lookahead_s=0)` 保持原来的零终端速度轨迹。显式启用 `lookahead_s`（最多 0.06 秒）后，控制器使用收到的目标差分估计速度，经过 20 ms 时间常数滤波，再将目标前移 `估计速度 × lookahead_s`。估计速度不超过配置的速度上限；目标也限制在原位置范围内。

预测只在收到新序号时计算，不在输入中断后继续外推。首次输入、暂停及超过 25 ms 的采样间隔重置估计。候选轨迹仍以零速度、零加速度结束，且整个轨迹的位置极值都必须通过检查。原有输入超时、乱序、非有限值和时钟倒退处理保持有效。

预测会改变停手和反向时的响应，可能增加短暂过冲。偏移上限不是机械臂实际过冲的保证。默认关闭以兼容现有部署；启用时需要同步部署 Python 策略和原生库。51 项旧配置仍可加载，非零预测使用 52 项配置，旧库会明确拒绝。

`streaming_probe` 使用 200 Hz、12 bit 量化输入与 1 kHz 参考更新，比较正弦、斜坡停止和边界反向；还检查暂停、恢复、丢包停车及参数校验。它支持额外速度上限参数，CTest 覆盖 0.35 和 0.5 rad/s。`reference_replay_test` 同时覆盖开启预测的历史边界轨迹。`test_server_roundtrip.py --lookahead-s ...` 在合成反馈上检查 TorchScript 上传、原生执行和超时停车，不连接真机。

## SpaceMouse 平移与姿态保持

`torchcontrol.policies.planar_impedance.PlanarImpedanceControl` 是显式选择的独立策略，不改变
`RobotInterface` 的默认控制器。虽然类名保留 Planar，它已支持 XYZ 速度输入；
接管时保存实测位置与朝向，之后积分平移目标并保持该朝向。应用层通过 Vela bridge
的 `--planar-config` 提供模型身份、增益、速度、工作空间和力矩预算。

控制器对速度及加速度做连续处理，限制目标相对实测位置的超前量，避免目标积压。
暂停或失联停止推进目标。绝对工作空间边缘只限制向外分量；向内恢复和切向移动保留，
实测位置短暂超界不会把所有轴永久闩锁。

输出先给偏置项与姿态保持分配关节力矩预算，再在剩余预算内按同一比例缩放平移力矩；
`planar_translation_scale` 暴露这项缩放。最终每关节预算仍有效，不通过提高原生阈值
解决姿态优先级问题。此预算是命令力矩限制，不是实测碰撞力的保证。

接触模式的兼容接口仍存在，但当前双输入数采页面使用统一 XYZ／姿态保持操作，
不显示接触模式选择。竖直有界阻抗与预载不构成实测接触力闭环。末端在接管时应采用
任务需要的朝向；后续真实运动的倾角、夹持滑动和桌面接触效果须另行测量。

`polymetis/tests/python/polymetis/test_planar_impedance.py` 覆盖策略计算、TorchScript、
暂停、边界恢复和姿态优先预算；`test_planar_server.py` 用合成反馈验证服务端往返。
服务器还须包含参数更新路径的 JIT 修复，避免首次参数更新在实时控制锁内触发优化。
完整组件来源见 [部署版本关系](../native/collection-release.md)。
